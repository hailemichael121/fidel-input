Engineering Precision

Built for Performance & Accuracy

Engineered from the ground up with mathematical syllabary symmetry and clean event decoupling.

Segmented Buffer Architecture

Decouples immutable committed syllables (lockedOutput) from active bounded matching (pendingFragment) for O(1) performance per keystroke.

Modern Framework Compatible

Bypasses React / Vue / Angular _valueTracker overriding issues on web inputs by invoking native prototype setters directly.

Syllable Disambiguation

Seamlessly handles ambiguous sequences with capital-vowel splitting (tE → ትእ, gEz → ግእዝ) and boundary overrides.

Personal Dictionary

User-defined phonetic overrides synced across devices via cloud storage that take precedence over default syllabary mappings.

Ethiopic Numerals (፩ - ፼)

Mathematical numeral positional converter transforming standard Arabic digits (1, 2, 3...) into traditional Ethiopic numerals.

Smart Phonetic Correction

Intelligently normalizes non-standard double-consonants and phonetic slips without interrupting the typing flow.

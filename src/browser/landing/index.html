What You Can Do With Fidel

Practical tips, shortcuts, and settings to make Amharic typing effortless in your daily workflow.

Natural Typing with Instant Syllable Resolution

Type normally using English phonetics. Fidel intelligently resolves consonants into their 7 orders and handles ambiguous compound syllables automatically:

  • Consonants + Vowels: s → ስ, se → ሰ, su → ሱ, si → ሲ, sa → ሳ, see → ሴ, so → ሶ
  • 8th Order Labialized: qwa / qw → ቋ, kwa → ኳ, lwa → ሏ, mwa → ሟ
  • Capital Vowel Shortcut (Split): Type capital E to insert standalone 6th order እ (e.g. gEz → ግእዝ, tE → ትእ)
  • Boundary Character: Use hyphen - to force separate syllables (e.g. t-e → ትእ)

Traditional Ethiopic Numerals & Punctuations

Easily toggle automated conversions on or off in the Extension Settings to match your exact formatting preferences:

  • Ethiopic Numerals (፩ - ፼): Automatically converts numbers: 1 → ፩, 10 → ፲, 25 → ፳፭, 100 → ፻, 2026 → ፳፻፳፮.
  • Ethiopic Punctuation: Automatically transforms standard keyboard punctuation:
    :: → ። (Full stop / Arat Netib)
    , → ፣ (Comma / Netela Serz)
    ; → ፤ (Semicolon / Dirb Serz)
    ? → ፧ (Question mark / Hiyek)

Smart Website Exclusions (Mini Browser Preview)

When typing code or design shortcuts on websites like GitHub, Figma, or CodePen, you want to type raw Latin without turning off Amharic mode manually. The Website Bypass List does this automatically:

  • All Standard Websites (e.g. twitter.com, docs.google.com, gmail.com): Fidel transliterates to Amharic automatically.
  • Bypassed Websites (e.g. github.com, figma.com, codepen.io): Fidel automatically stays in standard English (Latin) mode.
  • Global Shortcut: Press Alt + A (or Alt + Shift + A) anytime to toggle Fidel on or off on any page.

Developer & Engine Architecture

Technical specification of the Fidel core transliteration pipeline and cross-platform architecture.

Segmented Buffer Architecture

Decouples immutable committed syllables (lockedOutput) from active bounded matching (pendingFragment) for O(1) performance per keystroke.

Modern Framework Compatible

Bypasses React / Vue / Angular _valueTracker overriding issues on web inputs by invoking native prototype setters directly.

Prefix-Trie Mapping

O(k) longest-prefix match trie supporting 33 consonant roots, all 7 orders, and diqala compounds without regular expression overhead.
